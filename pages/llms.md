# OpenPeeps Blog

> OpenPeeps is an open-source collective led by George Lemon, focused on fast,
> small, and delightful tools and libraries written in the Nim programming
> language. This blog covers those projects, Nim development, and related
> experiments. Built with StupidGreen.

Site: https://openpeeps.dev
Author: George Lemon (https://github.com/georgelemon)
Organization: OpenPeeps (https://github.com/openpeeps)

## Topics

- Nim programming language
- Open-source libraries and developer tools
- Parsers, CLIs, web servers, and databases
- Static site generation
- LLMs and browser automation experiments

## Flagship projects

- [Tim](https://github.com/tim-engine/tim): a high-performance front-end engine for cool kids
- [Supranim](https://github.com/supranim/supranim): an MVC web framework for creating REST APIs and beautiful web apps in Nim
- [PowPow](https://github.com/openpeeps/powpow): a high-performance event library, an alternative to libuv and libevent
- [OpenParser](https://github.com/openpeeps/openparser): parsers and dumpers for JSON, CSV, TOML, YAML, RSS, and more
- [Booyaka](https://github.com/openpeeps/booyaka): a fast documentation generator
- [Marvdown](https://github.com/openpeeps/marvdown): a stupid simple Markdown parser
- [StupidGreen](https://github.com/openpeeps/stupidgreen): a stupid simple static site generator

## More libraries

- [Denim](https://github.com/openpeeps/denim): build Node and Bun addons from Nim through NAPI
- [Kapsis](https://github.com/openpeeps/kapsis): a CLI builder for Nim
- [TokTok](https://github.com/openpeeps/toktok): generic tokenizer for Nim
- [Bowdy](https://github.com/openpeeps/bowdy): a fast CSS preprocessor
- [Watchout](https://github.com/openpeeps/watchout): a fast, lightweight filesystem monitor
- [Valido](https://github.com/openpeeps/valido): a library of string validators
- [Flysystem](https://github.com/openpeeps/flysystem): a filesystem API for Nim
- [Boogie](https://github.com/openpeeps/boogie): WAL-based embedded data stores
- [Ozark](https://github.com/openpeeps/ozark): an ORM for Nim
- [Iconim](https://github.com/openpeeps/iconim): an SVG icon library manager for server-side rendering
- [Clue](https://github.com/openpeeps/clue): an alternative package manager for Nim
- [Carne](https://github.com/openpeeps/carne): a JavaScript runtime written in Nim
- [Vancode](https://github.com/openpeeps/vancode): a macro-based AST, codegen, and virtual machine
