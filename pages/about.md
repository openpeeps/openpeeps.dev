OpenPeeps is an open-source collective created by [George Lemon](https://github.com/georgelemon),
focused on building fast, small, and delightful tools and libraries in the
[Nim programming language](https://nim-lang.org). The work spans parsers, web
servers, command-line tools, databases, cryptography, and developer tooling.
Most projects are tiny, dependency-light, and meant to be used as standalone applications or
dropped straight into your own Nim applications.

This blog is where we will write about open source, free or commercial projects,
Nim development, alternative tools and whatever else shows up along the way: LLMs, browser
automation, CSS preprocessors, static site generators, and other experiments.

You can find all of our work on GitHub at [github.com/openpeeps](https://github.com/openpeeps).
Also, other related organizations [supranim](https://github.com/supranim) web framework, 
[tim-engine](https://github.com/tim-engine) and [nimbase](https://github.com/nimbase).

## Flagship projects

- [Tim](https://github.com/tim-engine/tim) - a pretty solid front-end engine with built-in VM, JIT, with optional source to source tranpsilation that feels like Pug.js on steroids... for real
- [PowPow](https://github.com/openpeeps/powpow) - a high-performance event library, an alternative to libuv and libevent
- [Supranim](https://github.com/supranim/supranim) - an MVC web framework for REST APIs and beautiful web apps in Nim, powered by PowPow library
- [Booyaka](https://github.com/openpeeps/booyaka) - a fast documentation generator built on top of Supranim
- [StupidGreen](https://github.com/openpeeps/stupidgreen) - the static site generator behind this blog. Built with Supranim ;)

## More libraries

- [OpenParser](https://github.com/openpeeps/openparser) - parsers and dumpers for JSON, CSV, TOML, YAML, RSS, and more
- [Marvdown](https://github.com/openpeeps/marvdown) - a stupid simple Markdown parser
- [Denim](https://github.com/openpeeps/denim) - build Node and Bun addons from Nim through NAPI
- [Kapsis](https://github.com/openpeeps/kapsis) - a CLI builder for Nim
