about this thing

OpenPeeps is an open-source collective created by George Lemon, focused on building fast, small, and delightful tools and libraries in the Nim programming language. The work spans parsers, web servers, command-line tools, databases, cryptography, and developer tooling. Most projects are tiny, dependency-light, and meant to be used as standalone applications or dropped straight into your own Nim applications.

This blog, is where we will write about open source, free or commercial projects, Nim development, alternative tools and whatever else shows up along the way: LLMs, browser automation, CSS preprocessors, static site generators, and other experiments.

You can find all of our work on GitHub at github.com/openpeeps. Also, other related organizations supranim web framework, tim-engine and nimbase.

🔗Flagship projects

  • Tim - a pretty solid front-end engine with built-in VM, JIT, with optional source to source tranpsilation that feels like Pug.js on steroids... for real
  • PowPow - a high-performance event library, an alternative to libuv and libevent
  • Supranim - an MVC web framework for REST APIs and beautiful web apps in Nim, powered by PowPow library
  • Booyaka - a fast documentation generator built on top of Supranim
  • StupidGreen - the static site generator behind this blog. Built with Supranim ;)

🔗More libraries

  • OpenParser - parsers and dumpers for JSON, CSV, TOML, YAML, RSS, and more
  • Marvdown - a stupid simple Markdown parser
  • Denim - build Node and Bun addons from Nim through NAPI
  • Kapsis - a CLI builder for Nim
